# Trabalho Avaliativo 2 — Programação de Sistemas Web

Dez programas em PHP (HTML + PHP + CSS), acessados por um menu em `index.php`.

## Estrutura

```
trabalho-avaliativo-2/
├── index.php        menu com as 10 questões
├── css/style.css    estilos (cartões, botões, formulários, responsivo)
├── questao1.php     número que somado a 230 dá 820
├── questao2.php     total da compra (computador + impressora)
├── questao3.php     distribuição de R$ 365 entre 18 pessoas e doação de R$ 7
├── questao4.php     salário semanal com bônus de 50% e 100%
├── questao5.php     valor a pagar conforme a condição de pagamento
├── questao6.php     IMC e classificação
├── questao7.php     três inteiros em ordem decrescente
├── questao8.php     número do mês por extenso
├── questao9.php     número de 1 a 5 por extenso
└── questao10.php    verificação e tipo de triângulo
```

## Como executar

**Servidor embutido do PHP** (PHP 8 instalado):

```
cd trabalho-avaliativo-2
php -S localhost:8000
```

Abra `http://localhost:8000` no navegador.

**XAMPP:** copie a pasta para `C:\xampp\htdocs\`, inicie o Apache no painel do XAMPP e abra
`http://localhost/trabalho-avaliativo-2/`.
